AIForBusiness

AIForBusiness — личный инструмент владельца канала «ИИ для Бизнеса» на YouTube. Он нарезает длинные видео на вертикальные шортсы и загружает их на канал владельца.

Приложение не предназначено для публичного использования: им пользуется только его владелец, и только для своего собственного канала.
